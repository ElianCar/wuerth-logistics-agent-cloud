<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| planner output to SlideSpec | Budgeted plan fields become renderer instructions and visible slide content. |
| SlideSpec to PPTX template | Renderer writes text, tables, and chart images into the tracked Wuerth PowerPoint master. |
| matplotlib image generation | Local chart payload becomes PNG bytes inserted into a PowerPoint package. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-02-01 | Tampering | `build_slide_deck_spec` | mitigate | Consume only validated planner fields and keep `validate_slide_deck_spec()` before `_render_presentation()`. |
| T-03-02-02 | Information Disclosure | metadata and visible slides | mitigate | Keep raw SQL in structured metadata only, keep visible output to planned summary, caveats, sources, truncation notes, and fallback reasons. |
| T-03-02-03 | Denial of Service | `_chart_image` and table rendering | mitigate | Cap chart rows, labels, body text, table rows, and table columns before rendering; fall back on image failures. |
| T-03-02-04 | Tampering | Wuerth template package | mitigate | Preserve `validate_template()` macro and external-relationship blockers before rendering. |
| T-03-SC | Tampering | package installs | accept | No new package-manager install is planned; matplotlib and python-pptx are already audited dependencies. |
</threat_model>
