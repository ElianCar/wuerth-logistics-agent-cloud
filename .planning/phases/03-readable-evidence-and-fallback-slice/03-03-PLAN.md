<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local record to JSON planner payload | Sanitized and capped record data may be sent to an optional model only when explicitly enabled. |
| JSON planner response to PresentationPlan | Untrusted model text is parsed and validated before any value can affect rendered slides. |
| planner fallback to exporter | Fallback warnings and audit metadata move from planner into export response. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-03-01 | Tampering | JSON planner response | mitigate | Parse strict JSON, validate schema fields, budgets, chart types, table ranges, and emphasis spans before merging. |
| T-03-03-02 | Information Disclosure | planner payload | mitigate | Send only capped rows, profiles, aggregates, SQL, and metadata; never read `.env` or include secrets. |
| T-03-03-03 | Denial of Service | optional planner invocation | mitigate | Default deterministic mode avoids model calls; enabled mode uses configured row and token caps and falls back on errors. |
| T-03-03-04 | Spoofing | planning audit | mitigate | Record actual `planning_mode` as deterministic, llm, or fallback based on executed path, not model claims. |
| T-03-SC | Tampering | package installs | accept | No package-manager install is planned; JSON validation uses stdlib and existing project modules. |
</threat_model>
