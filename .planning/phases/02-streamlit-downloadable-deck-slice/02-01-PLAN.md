## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Streamlit session state to UI | Generated PPT bytes and metadata are stored per user session and rendered back into the page. |
| Streamlit source to backend exporter | Streamlit must call the backend exporter instead of rendering PPTX content itself. |
