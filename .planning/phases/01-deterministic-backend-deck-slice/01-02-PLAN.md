## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Orchestrator record to export module | Record dictionaries are treated as untrusted until eligibility and spec validation pass. |
| Static template file to renderer | The PPTX template is a ZIP/OOXML package read from disk before rendering. |
| Export module to future Streamlit consumer | Returned bytes and metadata must be safe for a thin UI download surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-03 | Tampering | `build_slide_deck_spec` | mitigate | Validate slide types, layout names, budgets, and table limits before rendering. |
| T-01-04 | Information Disclosure | `build_presentation_export` | mitigate | Keep prompts, raw trace payloads, and broad audit JSON out of visible slides by default. |
| T-01-05 | Repudiation | `PresentationExport` metadata | mitigate | Include run id, validation state, source tables, warnings, and template audit in the structured return. |
| T-01-06 | Elevation of Privilege | PPTX generation path | mitigate | Do not accept model-produced PPTX bytes or runtime-generated slide code per D-06. |
| T-01-SC | Tampering | pip package install | mitigate | This plan depends on the blocking package checkpoint in Plan 01-01. |
</threat_model>
